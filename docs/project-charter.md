# NO-SIR1 — Project charter

Status: feasibility study; no site, supplier or investment approved.

Ploos AS aims to establish a small modular datacenter in Sirdal, Norway, initially operating one rack with provision for a second. It will serve internal SaaS workloads and affordable international Linux VPS customers, with hosting, cloud storage and backup as additional services.

Principles: scale with demand, energy efficiency, repairable hardware, automation, off-site backups and honest service commitments. Retain external infrastructure for independent monitoring and recovery. Ploos-VPS owns the customer platform; this repository owns physical infrastructure planning.

Public documentation must exclude precise site layouts, access details, credentials, customer information and operational security configurations.
